conninfpy.analysis
==================

The main entry point. :func:`conninfpy.analyze` runs the standard recipe —
input preparation (Fisher r→z, zero diagonal), optional multi-site
harmonization, GLM or two-sample / paired inference, and permutation
correction — and returns an :class:`~conninfpy.analysis.AnalyzeResult`.
