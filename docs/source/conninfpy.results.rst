conninfpy.results
=================

Result types returned by every inference pipeline:
:class:`~conninfpy.results.InferenceResult` (directional ``positive`` /
``negative`` p-values) and :class:`~conninfpy.results.OmnibusInferenceResult`
(F-contrast ``omnibus`` p-values), with significant-edge tables and exports.
