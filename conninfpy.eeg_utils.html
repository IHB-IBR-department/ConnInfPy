conninfpy.eeg_utils.read_from_eeg_dataframe(path_to_df, cond_prefix='fo', band_list=None)[source]

Read EEG connectivity data from a wide CSV into an EEGData.

The CSV has one row per subject and one column per <cond_prefix>_<band>_<pair> entry; the 10-20 electrode pairs are reconstructed from the column names.

Parameters:

  • path_to_df (str) – Path to the CSV file.

  • cond_prefix (str, optional) – Condition prefix identifying the relevant columns (default 'fo').

  • band_list (list of int, optional) – Frequency bands to keep; defaults to all seven Bands.

Returns:

With data of shape (n_subjects, n_chan_pairs, n_bands).

Return type:

EEGData

Examples

>>> eeg_data = read_from_eeg_dataframe('datasets/eeg_dataframe_nansfilled.csv', cond_prefix='fo')
>>> eeg_data.data.shape
(177, 171, 7)
conninfpy.eeg_utils.reshape_eeg_data(data: ndarray, reshape_bands: bool = True) → ndarray[source]

Unfold pair-indexed EEG data into per-band (n_chans, n_chans) matrices.

Parameters:

  • data (np.ndarray of shape (n_subjects, n_chan_pairs, n_bands)) – Pair-indexed data (a single subject may be passed as 2D).

  • reshape_bands (bool, optional) – If True, return block-diagonal matrices of shape (n_subjects, n_chans * n_bands, n_chans * n_bands) where each diagonal block is one band. If False, return (n_subjects, n_chans, n_chans, n_bands). Default True.

Returns:

Shape (n_chans, n_chans, n_bands) or (n_chans * n_bands, n_chans * n_bands) for single-subject input; batched shapes otherwise.

Return type:

np.ndarray

Notes

Assumes the 19-electrode 10-20 system (Electrodes).

Examples

>>> n_pairs = np.random.rand(2, len(PairsElectrodes1020(Electrodes).electrode_pairs), 3)
>>> reshape_eeg_data(n_pairs, reshape_bands=False).shape
(2, 19, 19, 3)
>>> reshape_eeg_data(n_pairs, reshape_bands=True).shape
(2, 57, 57)
