Beijing EOEC (China) Open-Close derivatives in this directory
==============================================================

The following files are derived from the Beijing Eyes-Open / Eyes-Closed
(Beijing EOEC) dataset and are NOT covered by ConnInfPy's MIT licence
(which applies to the code and documentation only):

  china_open_Schaefer200_strategy-4_GSR.npy    Schaefer-200 eyes-open time series
  china_close_Schaefer200_strategy-4_GSR.npy   Schaefer-200 eyes-closed time series
  subject_order_china.txt                      subject IDs aligned to row index

Source: FCP-INDI / NITRC Beijing EOEC dataset
https://fcon_1000.projects.nitrc.org/indi/retro/BeijingEOEC.html
