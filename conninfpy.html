Shared array helpers

fisher_r_to_z() (also exported as conninfpy.fisher_r_to_z()) and the connected-component labelling used by the enhancement operators.

Statistical utilities for ConnInfPy.

Includes:

  • fisher_r_to_z() / fisher_z_to_r() — Fisher transformations.

  • get_components() — connected components (BCT-style).

  • binarize() — threshold-and-binarize a connectivity matrix.

  • create_prior_weights() — block-density priors used by NI-TFNBS.

conninfpy._shared.arrays.fisher_r_to_z(r: NDArray[float64], handle_bounds: bool = True, max_z: float = 5, *, clip_r: float | None = None, return_report: Literal[True]) → tuple[NDArray[float64], dict]

Apply Fisher r-to-z transformation to correlation coefficients, handling boundary cases.

Parameters:

  • r (np.ndarray) – Array of correlation coefficients with values in [-1, 1]. Can be any shape (scalar, 1D, 2D, …).

  • handle_bounds (bool, optional) – Clip-z policy: if True (default), clip z to [-max_z, max_z] (this also makes r = ±1 finite). If False, keep the exact transform, with infinities at r = ±1 and a warning.

  • max_z (float) – Clipping bound of the clip-z policy (default: 5, i.e. |r| > tanh(5) ≈ 0.99991). Every value beyond it is clipped, so the transform stays monotone in r.

  • clip_r (float, optional) – Clip-r policy: clip correlations to [-clip_r, clip_r] before arctanh instead of clipping z afterwards (0 < clip_r < 1). This is the historical in-app “Apply Fisher-z now” behaviour (clip_r=0.9999, z bounded by atanh(0.9999) ≈ 4.9517, no warning). Mutually exclusive with handle_bounds=False; out-of- range input still raises.

  • return_report (bool, optional) – Also return a report dict with the number of clipped values, separating the structural diagonal (r = 1 by construction) from observed off-diagonal values, with explicit count units (matrix cells vs unique undirected edges vs observations). Under the unbounded policy nothing is clipped: the clipped counts are zero and values left at ±infinity are reported separately (left_at_infinity). Default False returns only the transformed array.

Returns:

z – Array of z-scores with the same shape as r (plus the report dict when return_report=True).

Return type:

np.ndarray

Raises:

ValueError – If any value in r is outside [-1, 1], or clip_r is not a number in (0, 1), or both clip_r and handle_bounds=False are given.

Warning

UserWarning

Under the clip-z policy: if r contains ±1 or values beyond tanh(max_z). With handle_bounds=False: if r contains ±1 (infinities are kept). The clip-r policy stays silent, as it has always been; use return_report for its counts.

Notes

The transformation is \(z = \operatorname{arctanh}(r)\). For \(r = \pm 1\), \(z\) approaches \(\pm\infty\). When handle_bounds=True, z is clipped at ±max_z. (Earlier versions replaced only values within np.isclose of ±1, so r = 0.99998 gave z = 5.76 while the larger r = 0.99999 gave 5.) Missing values (NaN) stay NaN.

Examples

>>> r_vals = np.array([1.0, -1.0])
>>> fisher_r_to_z(r_vals, handle_bounds=True, max_z=4.0)
array([ 4., -4.])

conninfpy._shared.arrays.get_components(A, no_depend=False)[source]

Connected components of an undirected binary graph.

Parameters:

  • A (np.ndarray of shape (N, N)) – Binary undirected adjacency matrix.

  • no_depend (bool, optional) – Does nothing; kept for backwards compatibility.

Returns:

  • comps (np.ndarray of shape (N,)) – Component index (1-based) assigned to each node.

  • comp_sizes (np.ndarray of shape (M,)) – Number of nodes in each component.

Raises:

ValueError – If A is not symmetric.

Notes

Isolated nodes form components of size 1. Component numbering is not guaranteed to match the BCT Matlab implementation, although the component topology is. Thanks to Nick Cullen for the original implementation.

Examples

>>> A = np.eye(3)
>>> comps, sizes = get_components(A)
>>> comps
array([1, 2, 3])
>>> sizes
array([1, 1, 1])
conninfpy._shared.arrays.binarize(W, copy=True)[source]

Binarize a weighted connectivity matrix: nonzero → 1, zero → 0.

NaN counts as absent data and becomes 0 — missing values must not turn into present edges. With copy=False the input array is modified in place.

Parameters:

  • W (np.ndarray of shape (N, N)) – Weighted connectivity matrix.

  • copy (bool, optional) – If True (default), return a new array; otherwise modify W in place.

Returns:

Binary adjacency matrix (0/1, same dtype behavior as input copy).

Return type:

np.ndarray of shape (N, N)

Examples

>>> W = np.array([
...     [0.0, 2.5, 0.0],
...     [1.1, 0.0, 0.3],
...     [0.0, 0.0, 0.0]
... ])
>>> binarize(W)
array([[0., 1., 0.],
       [1., 0., 1.],
       [0., 0., 0.]])
>>> binarize(np.array([np.nan, 0.0, 2.0]))
array([0., 0., 1.])
conninfpy._shared.arrays.create_prior_weights(node_labels: NDArray[int64], target_network_id: int | None = None, boost_factor: float = 2.0) → NDArray[float64][source]

Create an (N, N) symmetric weight matrix based on node network labels.

Parameters:

  • node_labels (np.ndarray[int]) – 1D array of integer network IDs for each node (length N).

  • target_network_id (int or None, optional) – If provided, only edges where both nodes belong to this network are boosted. If None (default), all intra-network edges (nodes sharing the same label) are boosted.

  • boost_factor (float, optional) – Multiplicative weight for priority edges (default 2.0).

Returns:

weights – Symmetric (N, N) weight matrix with background value 1.0 and boost_factor for priority intra-network edges. The diagonal is left at 1.0.

Return type:

np.ndarray[float]

Examples

>>> labels = np.array([1, 1, 2, 2])
>>> create_prior_weights(labels, boost_factor=3.0)
array([[1., 3., 1., 1.],
       [3., 1., 1., 1.],
       [1., 1., 1., 3.],
       [1., 1., 3., 1.]])
