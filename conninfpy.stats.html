conninfpy.stats

Advanced inference API — the permutation pipelines behind conninfpy.analyze(). Inputs are expected on the analysis scale (e.g. Fisher z); every pipeline returns an InferenceResult.

Permutation pipelines:

  • compute_p_val() — two-sample, paired and one-sample t-test designs

  • compute_p_val_glm() — Freedman–Lane GLM with t / β / F contrasts

  • compute_p_val_glm_multi() — several contrasts under one nuisance model, one permutation pass

  • compute_p_val_paired_glm() — paired A vs B with condition-varying confounds

  • compute_null_dist() — the max-statistic null distribution alone

Edge-wise statistics and designs: compute_t_stat(), compute_t_stat_diff(), compute_glm_stat(), build_design_matrix().

Enums: StatMethod, TestType, GLMStatType.

Permutation acceleration — conninfpy.stats.acceleration

Set acceleration='gpd' (or 'gamma') on either pipeline to replace the p-values that fewer than 10 permutations reach with a fitted tail (Generalized Pareto Distribution, Winkler 2016b); all other p-values stay exact. A goodness-of-fit guard (Anderson–Darling on tail exceedances) falls back to permutation p-values when the GPD does not fit cleanly.

Compute p-values using permutation testing with various network-based methods.

Warning

Two-sample statistic and group-label permutation

The two-sample path uses Welch’s t (separate group variances) by default and Student’s t (pooled variance) with var_equal=True; the observed statistic and every permutation use the same one, and the permutation (group-label shuffle, optionally within strata) is the same for both. The permutation test is exact when the groups are exchangeable under the null (same distribution). Under unequal variances with unbalanced group sizes exchangeability breaks and Type I error can inflate (Anderson & Robinson 2001; Hayes 2000); treat such results with caution whichever statistic is used. With equal group sizes the two statistics coincide.

Supports multiple statistical methods: tfnbs, tstat, nbs, cnbs, ni_tfnbs, fbc_tfnbs, bonferroni, bh_fdr, bh_fdr_perm.

Note

cNBS: block-level inference

method='cnbs' is the constrained NBS of Noble & Scheinost (2020): the signed t-statistic is averaged over every edge of each within- and between-network block (net_labels), each block is tested against its own permutation null (the same block’s mean in every permuted map), and the block p-values are corrected across blocks (cnbs_correction: Bonferroni for FWER, ‘bh’ for FDR). Every edge carries its block’s p-value; the result’s block_report lists the blocks. A significant block means that the block’s mean effect is nonzero, not that each of its edges is affected.

Note

Bonferroni and BH-FDR methods

StatMethod.BONFERRONI and StatMethod.BH_FDR are parametric baselines that do not use permutation testing. They compute p-values from the t-distribution and apply multiple comparison corrections. The n_permutations parameter is ignored for these methods. In the two-sample path, the parametric baseline uses edge-wise Welch-Satterthwaite degrees of freedom with Welch’s t, and n1 + n2 - 2 with Student’s t (var_equal=True).

Note

Permutation p-values

Empirical max-statistic p-values count ties conservatively (null >= observed) and use the Phipson-Smyth +1 correction: p = (count + 1) / (B + 1).

Run several contrasts of one design in a single permutation pass.

For studies with several predictors of interest in one model (e.g. testing age, sex and motion, each adjusted for the others), every contrast is tested against its own Freedman-Lane null: the reduced model X null(c) keeps the other predictors as nuisance, so a real effect of one predictor stays in the fitted part when another is tested. The permutations are shared (one seed per permutation, the same draw for every contrast), so each result equals compute_p_val_glm() for that contrast with the same rng; the pass shares the design pseudoinverse and the worker pool.

Contrasts are corrected separately (one family per contrast name, and per (e, h) cell); selecting the most significant contrast needs an extra correction.

The remaining keyword arguments are forwarded to the underlying GLM pipeline: method, two_tailed, acceleration, n_permutations, use_mp, rng, random_state, n_processes, verbose, net_labels, threshold, nbs_stat, e, h, n, start_thres, min_cluster_size and normalization (see compute_p_val_glm()).

Parameters:

  • Y (ndarray of shape (n_subjects, N, N)) – Connectivity tensor.

  • design_matrix (ndarray of shape (n_subjects, p)) – Full design matrix (intercept + all regressors of interest + nuisance).

Parent-side progress/cancel aggregator for one analysis call.

A session is created by the caller (analyze() or a UI job) and passed down through the pipelines as progress=session and cancel=<callable>. Each permutation loop announces itself to the session before it runs (see prepare_run()), so the total the session reports is the number of permutation executions planned so far across every loop/stage of the call — never an invented figure.

Contract

callback(done, total) is called in the parent process only, at chunk boundaries for permutations that were actually folded:

  • done is monotonic and never exceeds total;

  • total is monotonic non-decreasing and equals the sum of the permutation executions announced so far. For every current pipeline a single permutation loop of n_permutations seeds is run per analyze() call, and that loop is announced before its first seed, so total is exact from the first callback. Pipelines that run several loops (e.g. the available-case multi-contrast route, which runs one loop per contrast) grow total as each loop starts; done == total is only reported when all planned work has been redeemed and fully reduced;

  • the last callback of a successful call has done == total.

Cancellation is a parent-side decision: cancel is a zero-argument callable evaluated in the parent process at chunk boundaries. A threading.Event (or any UI callback) is therefore never pickled into a worker task payload. When it returns true the engine stops issuing chunks, terminates and joins the pool, removes its private task file and raises InferenceCancelled; the last done is not forced to total.

Compute p-values using permutation testing with various network-based methods.

Warning

Two-sample statistic and group-label permutation

The two-sample path uses Welch’s t (separate group variances) by default and Student’s t (pooled variance) with var_equal=True; the observed statistic and every permutation use the same one, and the permutation (group-label shuffle, optionally within strata) is the same for both. The permutation test is exact when the groups are exchangeable under the null (same distribution). Under unequal variances with unbalanced group sizes exchangeability breaks and Type I error can inflate (Anderson & Robinson 2001; Hayes 2000); treat such results with caution whichever statistic is used. With equal group sizes the two statistics coincide.

Supports multiple statistical methods: tfnbs, tstat, nbs, cnbs, ni_tfnbs, fbc_tfnbs, bonferroni, bh_fdr, bh_fdr_perm.

Note

cNBS: block-level inference

method='cnbs' is the constrained NBS of Noble & Scheinost (2020): the signed t-statistic is averaged over every edge of each within- and between-network block (net_labels), each block is tested against its own permutation null (the same block’s mean in every permuted map), and the block p-values are corrected across blocks (cnbs_correction: Bonferroni for FWER, ‘bh’ for FDR). Every edge carries its block’s p-value; the result’s block_report lists the blocks. A significant block means that the block’s mean effect is nonzero, not that each of its edges is affected.

Note

Bonferroni and BH-FDR methods

StatMethod.BONFERRONI and StatMethod.BH_FDR are parametric baselines that do not use permutation testing. They compute p-values from the t-distribution and apply multiple comparison corrections. The n_permutations parameter is ignored for these methods. In the two-sample path, the parametric baseline uses edge-wise Welch-Satterthwaite degrees of freedom with Welch’s t, and n1 + n2 - 2 with Student’s t (var_equal=True).

Note

Permutation p-values

Empirical max-statistic p-values count ties conservatively (null >= observed) and use the Phipson-Smyth +1 correction: p = (count + 1) / (B + 1).

Tail approximation — conninfpy.stats.acceleration

Permutation acceleration methods for faster inference.

Implements tail approximation via Generalized Pareto Distribution (GPD) and gamma approximation, following Winkler et al. (2016) “Faster permutation inference in brain imaging”, NeuroImage.

A finite set of J permutations resolves p-values down to about 1/J. Where fewer than MIN_EXCEEDANCES null maxima reach the observed statistic, the permutation p-value is too coarse and a fitted tail is used instead; every other p-value stays the exact permutation p-value (Knijnenburg et al., 2009). The fitted tail is an approximation, so the p-values it replaces are not exact.

References

Winkler et al. (2016). Faster permutation inference in brain imaging.

NeuroImage, doi:10.1016/j.neuroimage.2016.05.068

Knijnenburg et al. (2009). Fewer permutations, more accurate P-values.

Bioinformatics 25(12), i161-i168.

conninfpy.stats.acceleration.fit_gpd_tail(null_dist: NDArray[float64], observed: NDArray[float64], n_thresholds: int = 5, ad_threshold: float = 2.5, min_exceedances: int = 10, return_diagnostics: bool = False) → NDArray[float64][source]

Compute p-values with a GPD tail approximation where permutations are too few.

Every statistic first gets its permutation p-value. Only statistics that fewer than min_exceedances null maxima reach — where that p-value rests on a handful of permutations — get the GPD tail value instead. This is a tail approximation, not an exact finite-permutation procedure.

Algorithm (Winkler et al., 2016; Knijnenburg et al., 2009):

  1. Set the threshold u at the upper quartile of null_dist.

  2. Fit a GPD to the exceedances y = T_star_j - u by method of moments.

  3. Test the fit with Anderson-Darling; if poor, raise u (up to the 0.95 quantile) and retry.

  4. For the sparse-tail statistics, p = (k / J) * GPD_sf(T - u) where k is the number of exceedances.

Parameters:

  • null_dist (ndarray of shape (J,)) – Max-statistic null distribution from permutations.

  • observed (ndarray of shape (*spatial_dims,)) – Observed statistics (e.g., shape (N, N) for connectivity).

  • n_thresholds (int, default=5) – Number of thresholds tried between the 0.75 and 0.95 quantiles.

  • ad_threshold (float, default=2.5) – Anderson-Darling threshold for acceptable fit.

  • min_exceedances (int, default=10) – The GPD replaces the permutation p-value only for statistics reached by fewer than this many null maxima.

Returns:

p_values – Permutation p-values (tie-inclusive, Phipson-Smyth +1), with GPD values in the sparse tail when a good fit is found.

Return type:

ndarray of same shape as observed

Notes

Fitted values may be smaller than 1/J and are approximate. Observations below the fitted threshold retain empirical p-values. Fits whose finite upper endpoint excludes any candidate observation are rejected. Failed fits fall back to counting; the positive numerical floor guards underflow.

With return_diagnostics=True the return value is (p_values, count, replaced): the empirical exceedance counts actually computed here and a boolean mask of the cells whose p-value came from the fitted tail instead of the count. The p-values are identical either way.

Compute p-values using accelerated tail approximation.

Drop-in replacement for _compute_p_values_from_null that uses GPD or gamma fitting instead of pure empirical counting. Tail estimates are approximate; fallback empirical p-values use the same tie-inclusive max-statistic counting as the standard path.

Parameters:

  • emp_stat_dict (dict) – Dictionary with empirical statistic arrays (any keys).

  • max_null_dict (dict) – Dictionary with null distribution arrays.

  • method ({'gpd', 'gamma'}, default='gpd') – Acceleration method.

  • return_diagnostics (bool, default False) – Also return the empirical exceedance counts and the per-cell mask of tail replacements. Diagnostic only: no p-value changes, and the default return type is unchanged. Because the replacement choice is data-dependent, a conditional binomial interval is not valid for any cell of an accelerated result, including surviving empirical cells.

Returns:

Dictionary with p-value arrays for each key, and, with return_diagnostics=True, {'counts': {...}, 'replacement_mask': {...}} with arrays shaped like the p-values.

Return type:

dict or (dict, dict)
