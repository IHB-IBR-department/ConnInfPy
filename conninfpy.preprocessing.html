conninfpy.preprocessing

Three-state preprocessing facts carried with a dataset and its results.

Every fact is either unknown (absent / None) or known with an explicit source that separates what ConnInfPy itself did from what an input manifest or file name merely declares:

  • "computed_by_conninfpy" — the connectivity backend (conninfpy.compute_connectivity()) estimated the matrices.

  • "loader_denoising_pipeline" — the loader’s own denoising (e.g. fMRIPrep confound regression incl. its global-signal option).

  • "input_file_name_token" — a declaration encoded in the input file naming convention (e.g. ..._GSR.npy); not performed by this library.

  • "input_manifest_declared" — declared in the dataset manifest’s preprocessing.applied block about upstream processing.

  • "app_rank_correlation_pipeline" — the app ranked the series and the backend correlated the ranks (Spearman).

A missing key or a None fact means unknown, never “not applied”: an explicit False (e.g. global-signal regression known to be off) is kept as {"value": False, "source": ...} and must not collapse to missing. Known facts are never inferred from the connectivity values themselves (GSR is not guessed from negative edges).

Per-observation diagnostics live in the phenotype table, not here: n_valid_tr counts retained frames and delta_s is a per-subject shrinkage intensity in [0, 1] — neither is a repetition time. tr_seconds is only ever recorded from an explicit source; absent means unknown, not 1 or any other default.

conninfpy.preprocessing.KNOWN_CONNECTIVITY_METHODS = ('pearson', 'partial', 'spearman')

conninfpy.preprocessing.gsr_from_file_token(token: Any) → bool | None[source]

Global-signal status declared by a file-name token, or None.

"GSR" (case-insensitive, punctuation ignored) declares that global-signal regression was applied upstream; "noGSR" / "no_GSR" / "no-GSR" declare that it was not. Any other token declares nothing (None = unknown).

conninfpy.preprocessing.gsr_from_file_name(path: Any) → bool | None[source]

Global-signal status declared by a file name (not its contents).

Scans the base name for the GSR / negated-GSR tokens only; a name without a supported token declares nothing. Negation survives underscores, hyphens, dots and case (no_GSR, no-GSR, noGSR, no.gsr), and a negated token never reads as a plain GSR token; a GSR embedded in a larger word (e.g. xgsr) declares nothing.

conninfpy.preprocessing.empty_record() → dict[source]

A record with every fact unknown.

conninfpy.preprocessing.normalize_preprocessing_record(record: Any) → dict[source]

Validate (or accept None for) a preprocessing record; return a copy.

Unknown keys are rejected so typos cannot silently hide facts; every known fact must carry a value and a source. An explicit schema_version other than the supported one is rejected rather than silently rewritten (a future schema may mean something different); an absent version reads as the current one, as loaders building records programmatically do. The optional per_site mapping carries per-constituent records (e.g. per-site facts of a combined multi-site dataset) alongside the global facts; site records may not nest per_site again.

conninfpy.preprocessing.merge_preprocessing_records(*records: Any) → dict[source]

Merge records; earlier arguments win (library-computed beats declared).

Only facts missing from the higher-precedence record are filled in, so an explicit False from a performed pipeline is never overwritten by a manifest declaration.

conninfpy.preprocessing.aggregate_preprocessing_records(records: Any, *, names: Any = None) → dict[source]

Aggregate per-constituent records (e.g. per-site) into one record.

A fact is asserted globally only when every constituent states it with the same value: differing values, or a mix of known and unknown, leave the global fact unknown — never an invented common True/False. The aggregated source is the constituents’ shared source, or a mixed_sources(...) description when the agreeing facts arrived via different sources. Per-constituent records stay available to the caller (e.g. as provenance['preprocessing_per_site']) so heterogeneity is inspectable; names only labels the constituents.

conninfpy.preprocessing.attach_preprocessing(dataset: Any, **facts: Any) → dict[source]

Attach/extend dataset.provenance['preprocessing'] in place.

Each keyword is one fact value paired with its source either directly as a ('value', 'source') tuple or via fact(value, source); None facts are ignored. Facts already recorded on the dataset win (they were set by the component that actually did the work).

conninfpy.preprocessing.set_preprocessing_facts(dataset: Any, **facts: Any) → dict[source]

Overwrite facts recorded on a dataset (e.g. Spearman rank correlation).

Same calling convention as attach_preprocessing(), but the given facts replace whatever was recorded before, because the caller states what the data actually are after its own processing step.

conninfpy.preprocessing.record_from_manifest_applied(applied: Any) → dict[source]

Facts declared by a manifest preprocessing.applied block.

Recognised keys (everything else in the block is left alone, it stays available in the manifest itself): use_GSR/gsr (bool), correlation/connectivity_method (pearson/partial/spearman), standardize (bool), shrinkage (null/’ledoit_wolf’/’oas’/float), tr_seconds (positive number). Only declarations the block actually makes become facts; nothing is defaulted.
