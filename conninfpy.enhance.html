conninfpy.enhance

Network enhancement: the apply_* wrappers (shared stat_dict → score_dict transformations used by both the t-test pipeline (conninfpy.stats.pairwise) and the GLM pipeline (conninfpy.stats.glm)) and the raw scoring functions (get_*_score, nbs_bct).

These five wrappers are pure, key-agnostic transformations: a statistic dictionary keyed by effect direction ('g2>g1'/'g1>g2' for the two-sample / paired t-test, 'positive'/'negative' for the GLM, or 'omnibus' for the F-contrast pipeline) maps to an enhanced score dictionary with the same keys. Both the input statistic map and the output enhanced map are non-negative (N, N) symmetric matrices with zero diagonal.

The mathematical definitions of each operator are in the corresponding sections of the methods chapter.

Network enhancement: the apply_* wrappers plus the raw scoring functions.

The apply_* wrappers are shared by the t-test and GLM pipelines. Each wrapper is a pure transformation: stat_dict → score_dict. It takes a per-direction statistic dict ({'positive': ..., 'negative': ...}) and applies the corresponding network-based enhancement to each direction independently.

Wrappers accept the legacy keys 'g2>g1' / 'g1>g2' from the v1.x t-test pipeline (silently remapped via conninfpy._compat.normalize_keys() ) and return a TailResult with canonical 'positive' / 'negative' keys (a plain dict keyed 'omnibus' for an F-stat map). The legacy keys remain readable on the result with a DeprecationWarning until v2.1.

Wrappers do NOT compute statistics internally — the caller is responsible for providing the raw statistic (t-stat, β, etc.). This matches the design pattern documented in developer guide.

Constrained NBS (Noble & Scheinost, 2020): one statistic per block.

The signed edge statistic (positive - negative) is averaged over every edge of each within- and between-network block. Returns block vectors of shape (K,): the mean for the positive tail and minus the mean for the negative tail (or the mean F for an omnibus map). Inference is per block (see conninfpy.stats._cnbs), not by the maximum over edges.

conninfpy.enhance.apply_edge_mask(stat_dict: Dict[str, NDArray[float64]], edge_mask: NDArray[bool], inner=None, **kwargs) → TailResult | Dict[str, NDArray[float64]][source]

Restrict an enhancement to the edges of edge_mask (the tested family).

Statistics outside the mask are set to 0 before inner runs, so those edges cannot join a TFNBS / NBS cluster or count toward an NI-TFNBS block density; their score is 0 and never sets a permutation maximum, which makes the max-statistic FWER apply to the masked family. edge_mask is also passed to inner (NI-TFNBS counts block capacity over it). With inner=None the raw statistic is masked (method='tstat'). Module-level so it pickles to worker processes.

Transform connectivity matrix using Network-Informed TFNBS (Edge-Level Weighting).

This method uses Edge-Level Weighting: each edge’s support depends only on the density of its functional block, with NO topological clustering. Capacity M_b counts fixed eligible undirected edges, regardless of the observed/permuted statistic. Suprathreshold noise can still contribute to a block’s density; this is not a guarantee that noise is excluded.

Weighting Logic (depends on normalization):

  • 'sqrt': S_edge = k / sqrt(M_b) (default)

  • 'linear': S_edge = k / M_b (density)

  • 'none': S_edge = k (raw active count)

Key difference from standard TFNBS:

  • Standard TFNBS: edges cluster if they share a node (topological)

  • NI-TFNBS: each edge scored independently by block density

Parameters:

  • t_stats (ndarray of shape (N, N)) – Statistical matrix to be transformed.

  • net_labels (ndarray of shape (N,)) – Integer labels assigning each node to a functional network.

  • e (float or array-like) – Extent exponent.

  • h (float or array-like) – Height exponent.

  • n (int or None, default=None) – Exact integration when None; otherwise the historical right grid.

  • start_thres (float, default=1.65) – Initial threshold for cluster formation.

  • normalization ({'sqrt', 'linear', 'none'}, default='sqrt') – Block density normalization variant for ablation study.

  • edge_mask (ndarray of shape (N, N), optional) – Symmetric fixed eligibility mask. Ineligible edges contribute neither scores nor capacity. Defaults to all off-diagonal undirected pairs.

Returns:

tfnbs – Network-Informed TFNBS score matrix.

Return type:

ndarray of shape (N, N) or (N, N, num_params)

conninfpy.enhance.get_fbc_tfnbs_score(t_stats: NDArray[floating], net_labels: NDArray[integer], e: float | List[float] | NDArray[floating], h: float | List[float] | NDArray[floating], n: int | None = None, start_thres: float = 1.65, min_cluster_size: int = 3) → NDArray[floating][source]

Functional Block Clustering TFNBS (FBC-TFNBS).

This method clusters edges by functional block membership rather than topological connectivity. At each threshold:

  1. Edges are grouped by their functional block (e.g., Visual-Visual, DMN-DMN)

  2. If a block has k >= min_cluster_size edges, those edges support each other (support = k)

  3. If a block has fewer edges, they are considered “isolated” and suppressed (support = 0)

Key difference from standard TFNBS:

  • Standard TFNBS: edges cluster if they share a node (topological)

  • FBC-TFNBS: edges cluster if they’re in the same functional block

Key difference from NI-TFNBS:

  • NI-TFNBS: edge-level density weighting within predefined blocks

  • FBC-TFNBS: no topological clustering, isolated edges are suppressed

Parameters:

  • t_stats (ndarray of shape (N, N)) – Statistical matrix to be transformed (usually absolute t-values).

  • net_labels (ndarray of shape (N,)) – Integer labels assigning each node to a functional network.

  • e (float or array-like) – Extent exponent. Controls how much cluster size matters.

  • h (float or array-like) – Height exponent. Controls how much threshold height matters.

  • n (int or None, default=None) – Exact integration when None; otherwise the historical right grid.

  • start_thres (float, default=1.65) – Initial threshold for cluster formation.

  • min_cluster_size (int, default=3) – Minimum number of edges in a functional block to form a cluster. Blocks with fewer edges get support=0 (suppressed).

Returns:

tfnbs – FBC-TFNBS score matrix.

Return type:

ndarray of shape (N, N) or (N, N, num_params)

Notes

The key insight is that edges in the same functional block should support each other even if they don’t share any nodes. This captures the biological reality that effects within a functional system (e.g., Visual cortex) are likely related, while isolated edges are more likely noise.

Examples

>>> import numpy as np
>>> # Create a simple t-statistic matrix
>>> t = np.array([[0, 2.5, 1.8, 0.5],
...               [2.5, 0, 2.2, 0.3],
...               [1.8, 2.2, 0, 2.0],
...               [0.5, 0.3, 2.0, 0]])
>>> # Nodes 0,1 in network 0; nodes 2,3 in network 1
>>> labels = np.array([0, 0, 1, 1])
>>> scores = get_fbc_tfnbs_score(t, labels, e=0.5, h=2.0, n=20,
...                               start_thres=1.5, min_cluster_size=2)

NBS — conninfpy.enhance.nbs

Network-Based Statistics (NBS) scoring module.

Provides classical NBS cluster scoring (extent or intensity) and constrained cNBS scoring in a single module, mirroring the role of tfnbs_score.py.

conninfpy.enhance.nbs.get_nbs_score(t_stats: NDArray[floating], threshold: float = 3.0, stat_type: str = 'extent') → NDArray[floating][source]

Compute NBS cluster statistics for a t-statistic matrix.

Parameters:

  • t_stats (ndarray of shape (N, N)) – Non-negative t-statistic matrix (one tail, already separated).

  • threshold (float) – T-statistic threshold for edge inclusion.

  • stat_type ({'extent', 'intensity'}) –

    • ‘extent’: cluster size (# edges).

    • ’intensity’: sum over the cluster’s edges of the statistic minus the threshold, sum(t - threshold), as in the MATLAB NBS toolbox (NBSstats.m). Only the excess above the threshold counts: an edge just above it adds almost nothing, so the score does not jump when an edge crosses the threshold, and a small cluster of strong edges can outrank a large cluster of weak ones. Summing t itself would add threshold * extent, which makes intensity close to a rescaled extent.

Returns:

Matrix where each suprathreshold edge is assigned its cluster statistic. Non-suprathreshold edges are 0.

Return type:

ndarray of shape (N, N)

conninfpy.enhance.nbs.get_cnbs_score(t_stat: NDArray[float64], net_labels: NDArray[int64]) → NDArray[float64][source]

cNBS statistic (Noble & Scheinost, 2020) as an edge map.

Every edge gets the mean signed statistic of its block (all edges of the within- or between-network pair, whatever their sign or size). The inference unit is the block: see conninfpy.compute_p_val() with method='cnbs', which tests each block against its own permutation null and corrects across blocks.

Changed in version 2.0: Previously the mean of the strictly positive values of one tail, i.e. not the published statistic.

Parameters:

  • t_stat (ndarray of shape (N, N)) – Signed, symmetric edge statistic (e.g. t).

  • net_labels (ndarray of shape (N,)) – Network label of each node.

Returns:

Block mean on every off-diagonal edge; 0 on the diagonal.

Return type:

ndarray of shape (N, N)

Network-informed TFNBS — conninfpy.enhance.ni_tfnbs

Network-informed TFNBS: fixed-block capacity weighting.

conninfpy.enhance.ni_tfnbs.get_network_informed_tfnbs_score(t_stats: NDArray[floating], net_labels: NDArray[integer], e: float | List[float] | NDArray[floating], h: float | List[float] | NDArray[floating], n: int | None = None, start_thres: float = 1.65, normalization: str = 'sqrt', edge_mask: NDArray[bool] | None = None) → NDArray[floating][source]

Transform connectivity matrix using Network-Informed TFNBS (Edge-Level Weighting).

This method uses Edge-Level Weighting: each edge’s support depends only on the density of its functional block, with NO topological clustering. Capacity M_b counts fixed eligible undirected edges, regardless of the observed/permuted statistic. Suprathreshold noise can still contribute to a block’s density; this is not a guarantee that noise is excluded.

Weighting Logic (depends on normalization):

  • 'sqrt': S_edge = k / sqrt(M_b) (default)

  • 'linear': S_edge = k / M_b (density)

  • 'none': S_edge = k (raw active count)

Key difference from standard TFNBS:

  • Standard TFNBS: edges cluster if they share a node (topological)

  • NI-TFNBS: each edge scored independently by block density

Parameters:

  • t_stats (ndarray of shape (N, N)) – Statistical matrix to be transformed.

  • net_labels (ndarray of shape (N,)) – Integer labels assigning each node to a functional network.

  • e (float or array-like) – Extent exponent.

  • h (float or array-like) – Height exponent.

  • n (int or None, default=None) – Exact integration when None; otherwise the historical right grid.

  • start_thres (float, default=1.65) – Initial threshold for cluster formation.

  • normalization ({'sqrt', 'linear', 'none'}, default='sqrt') – Block density normalization variant for ablation study.

  • edge_mask (ndarray of shape (N, N), optional) – Symmetric fixed eligibility mask. Ineligible edges contribute neither scores nor capacity. Defaults to all off-diagonal undirected pairs.

Returns:

tfnbs – Network-Informed TFNBS score matrix.

Return type:

ndarray of shape (N, N) or (N, N, num_params)

Functional-block clustering TFNBS — conninfpy.enhance.fbc_tfnbs

Functional-block-clustering TFNBS scoring.

conninfpy.enhance.fbc_tfnbs.get_fbc_tfnbs_score(t_stats: NDArray[floating], net_labels: NDArray[integer], e: float | List[float] | NDArray[floating], h: float | List[float] | NDArray[floating], n: int | None = None, start_thres: float = 1.65, min_cluster_size: int = 3) → NDArray[floating][source]

Functional Block Clustering TFNBS (FBC-TFNBS).

This method clusters edges by functional block membership rather than topological connectivity. At each threshold:

  1. Edges are grouped by their functional block (e.g., Visual-Visual, DMN-DMN)

  2. If a block has k >= min_cluster_size edges, those edges support each other (support = k)

  3. If a block has fewer edges, they are considered “isolated” and suppressed (support = 0)

Key difference from standard TFNBS:

  • Standard TFNBS: edges cluster if they share a node (topological)

  • FBC-TFNBS: edges cluster if they’re in the same functional block

Key difference from NI-TFNBS:

  • NI-TFNBS: edge-level density weighting within predefined blocks

  • FBC-TFNBS: no topological clustering, isolated edges are suppressed

Parameters:

  • t_stats (ndarray of shape (N, N)) – Statistical matrix to be transformed (usually absolute t-values).

  • net_labels (ndarray of shape (N,)) – Integer labels assigning each node to a functional network.

  • e (float or array-like) – Extent exponent. Controls how much cluster size matters.

  • h (float or array-like) – Height exponent. Controls how much threshold height matters.

  • n (int or None, default=None) – Exact integration when None; otherwise the historical right grid.

  • start_thres (float, default=1.65) – Initial threshold for cluster formation.

  • min_cluster_size (int, default=3) – Minimum number of edges in a functional block to form a cluster. Blocks with fewer edges get support=0 (suppressed).

Returns:

tfnbs – FBC-TFNBS score matrix.

Return type:

ndarray of shape (N, N) or (N, N, num_params)

Notes

The key insight is that edges in the same functional block should support each other even if they don’t share any nodes. This captures the biological reality that effects within a functional system (e.g., Visual cortex) are likely related, while isolated edges are more likely noise.

Examples

>>> import numpy as np
>>> # Create a simple t-statistic matrix
>>> t = np.array([[0, 2.5, 1.8, 0.5],
...               [2.5, 0, 2.2, 0.3],
...               [1.8, 2.2, 0, 2.0],
...               [0.5, 0.3, 2.0, 0]])
>>> # Nodes 0,1 in network 0; nodes 2,3 in network 1
>>> labels = np.array([0, 0, 1, 1])
>>> scores = get_fbc_tfnbs_score(t, labels, e=0.5, h=2.0, n=20,
...                               start_thres=1.5, min_cluster_size=2)
