conninfpy.results

Result types returned by every inference pipeline: InferenceResult (directional positive / negative p-values) and OmnibusInferenceResult (F-contrast omnibus p-values), with significant-edge tables and exports.

Structured return types for the permutation pipelines.

Two levels:

  • conninfpy.analyze() returns an AnalyzeResult: the inference result (.inference) plus harmonization diagnostics and plain-English flags. Dict-style access (out['positive']) and the edge-table methods forward to .inference.

  • The advanced pipelines in conninfpy.stats return the InferenceResult / OmnibusInferenceResult defined here.

InferenceResult is a thin enrichment of TailResult that carries run-time metadata (method, n_permutations, acceleration, wall-time, optional null distribution), observed statistic maps, and provenance about any upstream harmonization step alongside the per-tail p-value matrices.

OmnibusInferenceResult is the sibling type returned by the F-statistic omnibus path (multi-row contrast). It carries the same metadata + provenance attributes but only a single 'omnibus' p-value map — F has no sign, so the positive/negative split is not defined for it.

Backward-compatible by design: both classes are dict subclasses (via TailResult), so existing code that accesses result['positive'] / result['negative'] (or result['omnibus'] for the F path) continues to work. The attribute APIs (result.positive, result.stat_signed, result.method, print(result)) are additive.

mc_report(alpha: float = 0.05, param_idx: int | None = None) → Dict[str, Any][source]

Monte-Carlo precision and RNG provenance for this result.

Describes, per tail: the number of permutations B, the numerical resolution 1 / (B + 1) (the smallest attainable p-value — a grid step, not an error bar), the theoretical permutation space (or None when it is ambiguous), whether the raw exceedance counts count are available, and a conditional binomial (Wilson) interval for count / B wherever one is justified.

What the numbers mean

The reported p-value is (count + 1) / (B + 1); the interval here is for the conditional exceedance probability count / B of a single draw, i.e. P(T* >= T_obs | H0), and never a bound on family-wise or FDR error. Because only B + 1 p-values are attainable, a p-value within about 1 / (B + 1) of a threshold (alpha) cannot be separated from it by this run; that is a resolution limit, not evidence for either side.

Tail policy: a two-sided result uses the joint null max(positive, negative), so both tails count against that same null (count_kind='joint_max'); their counts, and therefore their intervals, are not independent. Separate one-sided tails have their own counts. For bh_fdr_perm the reported p-values are BH-adjusted q values; the interval belongs to the underlying per-edge empirical count only.

Honesty rules: counts are the producer’s, never reconstructed from p-values. Untested cells keep the sentinel -1 (see exceedance_counts) and get no interval. Accelerated (GPD/gamma) results, cNBS block inference, available-case analyses and legacy results report interval status 'unknown' with the actual reason. Sampling is i.i.d. with replacement, so B above the permutation space only raises an informational flag (duplicate draws expected).

param alpha:

Two-sided confidence level 1 - alpha for the Wilson interval.

type alpha:

float, default 0.05

Cell of an (E, H) grid result; omit to describe the whole grid.

one_sided(direction: str) → InferenceResult[source]

Restrict a finished result to one direction — a post hoc selection.

Warning

The direction is chosen after the run, so the copy is marked tail_selection='post-hoc' in its provenance and exports; it is not a prespecified hypothesis. For a directional hypothesis fixed before seeing the data, declare it at launch with conninfpy.analyze()’s tested_tail= argument (the run then uses per-tail nulls and is marked 'prespecified'), or call the low-level pipeline with two_tailed=False.

Only a result computed with two_tailed=False can be restricted: each tail then has its own max-statistic null, and the kept tail’s p-values are one-sided FWER-corrected at the nominal level. The other tail’s p-values are set to 1, so tables, summaries and plots report no detections in the direction that was not tested; the statistic maps are kept unchanged. For method='nbs' the component report lists the tested tail’s components only, with the same component ids; for method='cnbs' the block report keeps all blocks of the family while marking the tested direction and dropping untested-tail p-values.

Parameters:

direction ({'positive', 'negative'}) – The tested direction of the contrast.

Returns:

A copy with tested_tail = direction, tail_policy = 'one-sided-<direction>' and tail_selection = 'post-hoc'.

Return type:

InferenceResult

Raises:

ValueError – For an unknown direction, or for a two-sided result: its p-values come from the joint null of both tails, which is not the null of a one-sided test.

coupling(profiles: Sequence[str] | None = None, *, near_zero: float = 0.0) → Dict[str, Any][source]

How coupling changes between two profiles (default: design['comparison']).

Returns {'profiles', 'a', 'b', 'delta', 'classes'}: the two predicted maps on the analysis scale, their difference in r units when the scale is Fisher z (tanh(b) - tanh(a); native units otherwise), and the class of each edge: stronger / weaker positive coupling, stronger / weaker anticorrelation, sign change, or, with a prespecified near_zero band, emerges from / returns to ~0. The classes are descriptive labels on the recorded scale. Negative baselines depend on preprocessing (global-signal regression both removes and induces anticorrelations); neither they nor their classes carry physiological or causal meaning by themselves. With partial-correlation input the scale is atanh(partial r), a variance-stabilizing transform — not the exact standard z of a marginal Pearson r.

significant_edges(atlas: Any | None = None, *, alpha: float = 0.05, tail: str = 'both', sort: str = 'p', include_nonsig: bool = False, top_k: int | None = None, param_idx: int | None = None) → Any[source]

Sorted table of significant edges with optional atlas annotation.

Parameters:

  • atlas (AtlasInfo, optional) – When supplied, adds ROI names, RS-network labels, hemisphere, and a canonical network_pair column. Length must match self['positive'].shape[0].

  • alpha (float, default 0.05) – Edge-wise significance threshold.

  • tail ({'both', 'positive', 'negative'}, default 'both') – Which tail(s) to filter on. 'both' keeps edges where either p_positive or p_negative falls below alpha; the per-row tail column reports which tail(s) actually hit significance for that edge.

  • sort ({'p', 'statistic', 'network_pair'}, default 'p') – Sort key. 'p' — ascending min(p_positive, p_negative). 'statistic' — descending absolute signed t/beta statistic. 'effect_size' remains a deprecated alias for 'statistic'; a t-statistic is not a standardized effect size. 'network_pair' — group by canonical network pair, then by p ascending within group; requires atlas.

  • include_nonsig (bool, default False) – If True, include all edges (not just significant ones).

  • top_k (int, optional) – Keep only the top-K rows after sorting.

Returns:

Columns (with atlas): edge_id, roi_i, roi_i_name, roi_i_network, roi_j, roi_j_name, roi_j_network, network_pair, t_signed, p_positive, p_negative, p_min, tail, hemisphere_i, hemisphere_j. Without an atlas the roi_*_name, roi_*_network, hemisphere_* and network_pair columns are omitted. A method='nbs' result adds component_tail and component_id after tail: the component (see component_report) the edge belongs to, numbered within its tail; <NA> for an edge above no threshold. Edges of one component share one p_*.

Return type:

pandas.DataFrame

Notes

Interpret detections at inference_unit: cNBS rows project block p-values and NBS rows represent component detections; neither gives an individual edge localization claim. With separate one-sided families, filtering both tails at alpha does not imply joint FWER at alpha. Statistical detection alone does not establish a biological mechanism. For reporting, prefer block-level patterns (roi_i_network × roi_j_network) over individual edges — use sort='network_pair' to group them.

Raises:

ValueError – If stat_positive / stat_negative are missing (e.g. pre-v2.1 results, or objects created without stat maps), or if sort='network_pair' without an atlas.

component_table(atlas: Any | None = None, *, alpha: float = 0.05, tail: str = 'both', significant_only: bool = False) → DataFrame[source]

Components of an NBS result: one row per observed component.

The inference unit of method='nbs' is the connected component of the edges above the threshold, calibrated against the permutation distribution of the maximum component statistic (FWER). Every observed component is listed, significant or not, as block_report lists every block; significant is p_fwer <= alpha and significant_only=True keeps those rows.   • tail ({'both', 'positive', 'negative'}, default 'both')

  • significant_only (bool, default False)

Returns:

tail, component_id, n_edges, n_nodes, statistic, statistic_type, p_fwer, significant, nodes (+ atlas columns); statistic is the extent or the intensity sum(t - threshold). The threshold and the permutation count are in df.attrs. Ids are numbered within each tail by decreasing statistic.

Return type:

pandas.DataFrame

Raises:

ValueError – If the result is not from method='nbs'.

node_summary(atlas: Any | None = None, *, alpha: float = 0.05, tail: str = 'both', param_idx: int | None = None, sort: str = 'detections', top_k: int | None = None) → DataFrame[source]

Which ROIs gather the detected connections: one row per ROI.

A descriptive summary: it adds no p-value and no new significance and leaves the result unchanged. What counts as a detection of a ROI follows inference_unit.

Edge results (tstat, bh_fdr, bh_fdr_perm, tfnbs, ni_tfnbs, fbc_tfnbs; every edge has its own p-value). Per tail: n_sig_<tail> (incident edges with p <= alpha) and prop_sig_<tail>; n_sig_total / prop_sig over the edges significant in either tail; n_tested is the denominator, the incident edges that were tested: an edge outside an edge_mask family or with too few subjects under missing='available_case' has a NaN p-value and is in neither numerator nor denominator (so it is not simply N - 1). mean_effect_<tail> is the mean contrast effect c' beta (effect_map(), the effect column of significant_edges()) over the ROI’s significant edges of the tail; NaN when the result carries no effect map (never replaced by t or by an enhanced score) or the ROI has no significant edge.

Component results (nbs) and block results (cnbs). All edges of a component or block share one p-value, so a count of significant edges or a mass of -log10 p says nothing about a ROI. The summary lists, per tail, the significant (p_fwer / corrected p <= alpha) components or blocks that contain the ROI (component_ids_<tail> / block_ids_<tail>, blocks as 'A—B'), their number, and how many of the ROI’s tested edges lie in them (n_edges_in_components_<tail> / n_edges_in_blocks_<tail>; totals without the suffix). The column inference_unit and DataFrame.attrs['descriptive'] mark the table as descriptive.

Networks. With an atlas that has network labels, the partner networks of the ROI’s detections (its significant edges, or its edges in the significant components / blocks) are given as partner_networks ('Net (k)' counts), n_networks_reached and participation, the participation coefficient of Guimera & Amaral (2005), P = 1 - sum_s (k_s / k)**2 over partner networks s. It is NaN, not 0, for a ROI without detections, and 0 when all its detections go to one network (also when it has a single one: read it together with n_sig_total / n_edges_in_*). Without an atlas, or with an atlas without network labels, those columns (and network) are absent; nothing is guessed.

Parameters:

  • atlas (AtlasInfo, optional) – Adds roi_name, network and hemisphere where the atlas has them. Length must match the number of ROIs.

  • alpha (float, default 0.05) – Significance threshold of edges, components or blocks.

  • tail ({'both', 'positive', 'negative'}, default 'both') – Tails to report. After one_sided() only the tested tail exists; asking for the other raises ValueError. With two_tailed=True results both tails are reported; attrs['tail_policy'] records the declared family.

  • param_idx (int, optional) – Cell of an (E, H) parameter grid (as in significant_edges()).

  • sort ({'detections', 'roi'}, default 'detections') – 'detections': by n_sig_total (edge results) or by the number of the ROI’s edges in significant components / blocks, descending, ties by ROI index; 'roi': by ROI index.

  • top_k (int, optional) – Keep the first top_k rows after sorting.

Returns:

One row per ROI: roi (+ roi_name, network, hemisphere), inference_unit, the count columns above, n_tested (+ the network columns). DataFrame.attrs holds alpha, inference_unit, tails, tail_policy, tested_tail, method, param_idx (and e / h of a grid cell), descriptive, denominator and effect_source.

Return type:

pandas.DataFrame

Raises:

ValueError – For a grid result without param_idx, a tail that was not tested, a wrong atlas length, or a component / block result whose report is missing (made before the report was recorded).

network_summary(atlas: Any, *, alpha: float = 0.05, param_idx: int | None = None, as_matrix: str | None = None) → DataFrame[source]

conninfpy.results.summarize_by_network(p_maps: Any, networks: Any, *, alpha: float = 0.05, as_matrix: str | None = None) → DataFrame[source]

Aggregate edge-wise p-value maps over pairs of atlas networks.

One row per unordered network pair (within-network pairs included): the number of possible edges, the number and proportion of edges with p <= alpha per tail, and the -log10 p mass per tail (sum and mean over the block). Network-pair summaries are typically far more reproducible across cohorts than individual edges, so report them alongside edge tables.

Parameters:

  • p_maps (dict of str -> ndarray of shape (N, N), or ndarray) – P-value maps keyed by tail, e.g. {'positive': p_pos, 'negative': p_neg}; a single array is summarized as tail 'p'. Edges are taken from the upper triangle.

  • networks (AtlasInfo or sequence of str) – An atlas (its per-ROI networks field defines the partition) or one network label per ROI. Any user-defined partition works.

  • alpha (float, default 0.05) – Significance threshold (p <= alpha).

  • as_matrix (str, optional) – Return one column as a symmetric K × K DataFrame (networks in first-appearance order) instead of the table, e.g. 'sum_neglog10p_positive' or 'signed_proportion'.

Returns:

Columns network_a, network_b, network_pair, within_network, n_edges, and per tail t: n_sig_t, prop_sig_t, sum_neglog10p_t, mean_neglog10p_t; plus signed_proportion = (n_sig_positive - n_sig_negative) / n_edges when both directional tails are given.

Return type:

pandas.DataFrame

Examples

>>> import numpy as np
>>> p = np.full((4, 4), 0.5); p[0, 1] = p[1, 0] = 0.01
>>> summarize_by_network({"positive": p}, ["A", "A", "B", "B"])[
...     ["network_pair", "n_edges", "n_sig_positive"]]
  network_pair  n_edges  n_sig_positive
0          A—A        1               1
1          A—B        4               0
2          B—B        1               0
