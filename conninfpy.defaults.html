conninfpy.defaults

TFNBS-family scoring defaults to E=0.4, H=3.0 and exact integration of its piecewise support function (n=None). A positive integer n selects the historical right-endpoint grid from start_thres + dh to max(statistic), where dh = (max - start_thres) / n. Active edges satisfy weight >= threshold after the initial strict weight > start filter. Inputs are rounded to ten decimal places before integration.

Record E, H, n, the start threshold, statistic scale and software version to reproduce an earlier run. Explicit n retains the old grid; exact scores and p-values need not equal finite-grid results. bh_fdr_perm uses raw edge statistics and does not use TFNBS integration settings. T and beta tails are enhanced separately; an F statistic is a single omnibus map.

For F with TFNBS and no start supplied, the start is F’s 0.90 quantile with the numerator and residual degrees of freedom. With available-case data and different tested residual degrees of freedom, provide one common start explicitly. An explicitly supplied F start below any applicable quantile emits a warning. Beta thresholds remain in coefficient units.

Unified default parameters for ConnInfPy.

Single source of truth for all default constants used across modules.

TFNBS defaults use E=0.4 and H=3.0. By default n=None integrates the piecewise support exactly, independently for each tail. An explicit positive integer n selects the historical right-endpoint grid, with threshold levels start + i * (max - start) / n and inclusive active edges at each level. Legacy finite-grid scores and the exact integral need not be equal. Record E, H, n and start explicitly when reproducing historical results.

The permutation-based BH-FDR method uses raw edge statistics and does not apply TFNBS enhancement or its integration settings.

  • Baggio et al. (2018). Statistical inference in brain graphs using threshold-free network-based statistics. Hum Brain Mapp 39(6):2289-2302. doi:10.1002/hbm.24007.

  • Vinokur, L., Smith, R. E., Dhollander, T., Vaughan, D., Jackson, G. D., & Connelly, A. (2023). Parameter Sensitivity of Network-Based Statistical Inference. Research Square (preprint), doi:10.21203/rs.3.rs-3081615/v1.

  • Hao, Z., Wang, P., Xia, X., Pan, Y., & Dou, W. (2024). Threshold-Free Network-Oriented Statistics in Neuroscience (TFNOS). bioRxiv (preprint), doi:10.1101/2024.01.03.574016. For edge-wise t-statistics in TFNOS-TT, E=0.4, H=3.0 yielded empirical FDR < 10% and E=0.4, H=7.0 empirical FDR < 5%; earlier voxel/network defaults such as Baggio 2018 were overly liberal in the reported conditions.

conninfpy.defaults.DEFAULT_START_THRESHOLD: float = 1.65

Initial t-threshold for cluster formation (asymptotic normal z ≈ 1.645 reference, one-tailed p ≈ 0.05 at large df; not a universal finite-df p-value).

conninfpy.defaults.DEFAULT_N_THRESHOLDS_SCORING = None

None selects exact integration; a positive integer selects the legacy grid.

conninfpy.defaults.DEFAULT_N_THRESHOLDS_PERMUTATION = None

None selects exact integration inside the permutation loop.

Default number of permutations for null distribution.

conninfpy.defaults.DEFAULT_ACCELERATION = None

None (exact empirical permutation p-values).

'gpd' / 'gamma' are opt-in for exploration with ~200 permutations: a fitted tail replaces the p-values that fewer than 10 permutations reach (Winkler 2016); all others stay exact.
