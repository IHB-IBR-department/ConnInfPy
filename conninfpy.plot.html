conninfpy.plot

Diagnostic plotting helpers for ConnInfPy results.

Per-panel helpers and a one-call publication figure:

  • plot_block_mass() — Yeo-7 (or arbitrary partition) block-mass heatmap of significant edges.

  • plot_p_map() — symmetric edge-level p-value heatmap with optional significant-edge highlight.

  • plot_null_max_distribution() — max-stat null distribution histogram with optional GPD tail-fit overlay.

  • plot_effect_matrix() — signed effect heatmap (RdBu_r, symmetric vmax) with significant edges outlined; optional network-block ordering when an AtlasInfo is supplied.

  • plot_network_summary() — P × P block heatmap of the signed proportion of significant edges per (network_i × network_j) cell; more robust than the edge-level map at high node counts.

  • summary_figure() — publication-ready 2×2 layout combining the effect matrix, block summary, p-maps, and top-k edge table.

  • plot_connectogram() — Brainnetome-style circular connectogram of the detected connections, aggregated to BNA subregions or gyri, with chords coloured by the endpoints’ functional networks.

  • plot_coupling_classes() — categorical heatmap of how coupling changes between two profiles (descriptive classes from InferenceResult.coupling()), optionally marking BNA homotopy pairs and overlaying the edges of the result’s detected units.

Each per-panel helper accepts an optional ax= argument (creating a fresh figure if omitted) and returns the matplotlib.axes.Axes so the caller can compose multi-panel figures. summary_figure() returns a matplotlib.figure.Figure.

Importing conninfpy.plot requires matplotlib. The plotting helpers are intentionally not imported at the top level of conninfpy — call import conninfpy.plot only if you need them, so headless environments (CI, batch jobs) don’t pull matplotlib.

conninfpy.plot.plot_network_summary(result: Any, *, atlas: AtlasInfo, alpha: float = 0.05, ax: Axes | None = None, cmap: str = 'RdBu_r', annotate: bool = True, title: str | None = None) → Axes[source]

K × K block heatmap of the signed proportion of significant edges.

For each pair of networks (i, j) (canonical, unordered), the cell value is

\[s_{ij} = \frac{n_{ij}^{+} - n_{ij}^{-}}{n_{ij}^{\text{total}}}\]

where n_{ij}^{+} and n_{ij}^{-} are counts of significant positive- and negative-tail edges with one endpoint in network i and the other in network j, and the denominator is the total number of edges in that block. The ratio is bounded in [-1, 1]; +1 means every block edge is significantly positive, -1 significantly negative, 0 no net direction.

For the F-stat omnibus path the cell holds the unsigned proportion n_{ij} / n_{ij}^{total} and the colormap defaults to a sequential scheme.

Parameters:

  • result (InferenceResult or OmnibusInferenceResult) – Inference output (uses result['positive'] / ['negative'] or ['omnibus'] p-value maps).

  • atlas (AtlasInfo) – Required — supplies the per-ROI network labels.

  • alpha (float, default 0.05) – Significance threshold.

  • ax (matplotlib Axes, optional) – Plot into this axis; otherwise a new figure is created.

  • cmap (str, default "RdBu_r") – Matplotlib colormap (sequential for the F-stat path).

  • annotate (bool, default True) – Print the cell value inside each block.

  • title (str, optional) – Axis title.

Publication-ready 2 × 2 summary of a ConnInfPy inference run.

Panels:

  • top-left: plot_effect_matrix() (network-ordered if an atlas is supplied).

  • top-right: plot_network_summary() if an atlas is supplied, otherwise plot_block_mass() with a fallback single-block partition.

  • bottom-left: plot_p_map() of the positive tail (-log10 p heatmap; for the F-stat path the single omnibus map is shown).

  • bottom-right: top-top_k row table from result.significant_edges(atlas, sort='p').

  • alpha (float, default 0.05) – Significance threshold used by every panel.

  • top_k (int, default 10) – Number of rows in the edge table.

  • title (str, optional) – Figure-level title.

  • figsize (tuple of float, default (12, 9)) – Inches.

conninfpy.plot.plot_connectogram(result: Any, rois: Any, *, tail: str = 'positive', level: str = 'gyrus', alpha: float = 0.05, assign: str = 'dominant', networks: Sequence[str] | None = None, weight: str = 'count', min_weight: float = 1.0, max_links: int | None = None, labels: str = 'gyrus', title: str | None = None, ax: Axes | None = None, param_idx: int | None = None) → Axes[source]

Brainnetome-style connectogram of one tail’s detected connections.

The layout follows the BNA-246 connectogram: left hemisphere on the left, right mirrored on the right, lobes from frontal (top) to subcortical (bottom). Rings, from outside in: the 246 subregions (pale = not sampled by any ROI), the gyri, and the network make-up of each unit at level (the share of its sampled tissue that comes from ROIs of each network).

Connections are aggregated with conninfpy.interpret.annotate.aggregate_connections(), split by each ROI’s network label (networks, default rois.table['network']: the source atlas’s division, see conninfpy.interpret.annotate.annotate_rois()). By default each ROI is placed in the unit holding most of its tissue (assign='dominant'), so every chord is a whole number of connections and none is dropped. assign='weighted' spreads each ROI over the units its support covers; that is faithful to mixed ROIs, but splits a connection between large parcels into many fractional chords, most below min_weight (the footer gives the share of connections drawn). aggregate_connections itself defaults to the fractional 'weighted'.

ROIs that annotate_rois marked level == 'unassigned' (no labelled support in the atlas, or a labelled share below its min_coverage) are not placed: they get no tissue on the rings and none of their chords, and the footer reports how many were left out and why, together with how many detected connections touch such an ROI. The full counts live in the attrs['coverage'] of the underlying aggregation (see conninfpy.interpret.annotate.aggregate_connections()).

A chord joins two (unit, network) slots; its colour runs from one endpoint’s network to the other’s, and its width scales with the number of detected connections (weight='count') or detected / tested ('rate'). Chords below min_weight connections are not drawn.

Descriptive only: the result’s correction and inference unit are unchanged.

conninfpy.plot.plot_coupling_classes(result: Any, *, profiles: Sequence[str] | None = None, near_zero: float = 0.0, atlas: 'AtlasInfo' | None = None, reference: 'BrainnetomeReference' | None = None, alpha: float | None = None, ax: Axes | None = None, title: str | None = None) → Axes[source]

Categorical heatmap of how coupling changes between two profiles.

The matrix is descriptive and covers every cell whose two predicted profiles are both available: the class of a cell is the class of its a → b change at the recorded scale, computed from result.predicted() for the two profiles and taken verbatim from conninfpy.InferenceResult.coupling() (see conninfpy.stats._estimates.COUPLING_CLASSES) — this helper classifies nothing itself. A NaN in either predicted profile leaves the cell without a class, drawn as the neutral 'missing' category. The plot is symmetric and drawn in full; the diagonal is masked. Classes are descriptive labels on the recorded scale, not evidence of significance, and the colour matrix stays fully descriptive at any alpha.

Homotopy pairs are marked from BNA metadata only: with an atlas that carries label_ids (BNA roi_id per matrix row) and a BrainnetomeReference`, a cell is marked when the two ids are each other’s homolog_id. Without those metadata all pairs are unknown and the legend says so; an id absent from reference.regions makes its pairs unknown as well. Homology is never inferred from ROI order, symmetry or name suffixes.

Parameters:

  • result (InferenceResult) – Result carrying coefficient maps and a design with a comparison (see conninfpy.InferenceResult.coupling()).

  • profiles (sequence of str, optional) – Two profile names, forwarded to result.coupling. Default: the design’s recorded comparison.

  • near_zero (float, default 0.0) – Prespecified “~0” band forwarded to result.coupling; it decides the emerges-from / returns-to classes. The plot introduces no band of its own.

  • atlas (AtlasInfo, optional) – Supplies label_ids (BNA ROI id per matrix row) and labels for the axes. Its length must match the matrix.

  • reference (BrainnetomeReference, optional) – Source of homolog_id. Requires atlas.label_ids; otherwise every pair is unknown.

  • alpha (float, optional) – If given, outline the edges returned by result.significant_edges(alpha=alpha, tail='both'). For an edge-level result these are significant edges; for nbs / cnbs results they are the edges of the detected components / blocks, and the legend says exactly that. The contour bounds the overlay only; the colour matrix keeps its descriptive meaning. No new threshold, p-value or edge discovery is introduced here, and the contour is not a joint detection claim: as noted for InferenceResult.significant_edges(), with separate one-sided families filtering both tails at alpha does not imply joint FWER at alpha.

  • ax (matplotlib Axes, optional) – Plot into this axis; otherwise a new (5.6, 5.0) figure is created.

  • title (str, optional) – Axis title. Defaults to the compared profiles.

Returns:

The axis, carrying attrs:

descriptive (True), inference_unit (result.inference_unit), applies_to (always the scope of the colour matrix: 'descriptive coupling classes of cells with available predicted profiles'), contour (None when alpha is None - no contour is drawn; otherwise a dict with 'applies_to' ('significant edges' for edge results, else 'edges of the detected components|blocks'), 'alpha' (float) and 'label' (the legend text of the overlay)), homology ('bna homolog_id' or 'unknown'), and the descriptive extras homotopy_pairs, homology_unknown_rois, profiles, near_zero, alpha.

The legend lists the class strings present in the matrix in COUPLING_CLASSES order — the same strings as the coupling_change column of InferenceResult.annotated_edges() — plus 'missing' for NaN cells, the homotopy marker and, where applicable, an explicit “homology unknown” entry.

Return type:

matplotlib.axes.Axes

Raises:

ValueError – If the result carries no design / comparison (raised by InferenceResult.coupling()), or if atlas / label_ids length does not match the matrix.

Notes

Interpretation follows InferenceResult.inference_unit: with cnbs (blocks) or nbs (components) the alpha overlay shows the edges inside detected units, never edge-level significance. Negative baselines and the classes derived from them depend on preprocessing and carry no physiological or causal meaning on their own.
